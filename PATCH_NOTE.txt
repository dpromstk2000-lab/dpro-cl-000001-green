DPRO GREEN CONTACT R3.10.4 / ZERO-JUMP
2026-09-27

R3.10.3でも動いたため、方式を変更。

今回の完成方針:
- 30秒ごとに新着確認は続ける
- バックグラウンド確認では visible DOM を絶対に再描画しない
- 新着があれば「新しいメッセージがあります ↓」だけ表示
- オペレーターがそのボタンを押した時だけ履歴を更新
- タブ復帰時のbase CONTACT自動refreshも抑止
- browser scroll anchoringをOFF
- 履歴画像は高さ200pxを先に確保し、画像読み込み後のレイアウト変動を防止

これにより:
新着確認 = 自動
画面移動 = ユーザー操作時だけ

変更なし:
LINE送受信 / 画像 / PDF / 送信確認 / Worker / SQL / Secret

確認:
1. contact-green.html?dpro_build=1 をCtrl+F5
2. 任意の位置で3〜5分そのまま待つ
3. スクロール位置が動かない
4. スマホLINEから新着を1件送る
5. 位置は動かず「新しいメッセージがあります ↓」が出る
6. ボタンを押した時だけ最新へ移動
