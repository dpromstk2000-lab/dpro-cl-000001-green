DPRO GREEN SHOP V3-C.1 PHOTO UX
2026-09-27

スクリーンショット確認から、オーナー操作性をさらに改善。

改善点
====
1. ブラウザ標準の英語表示
   Choose Files / No file chosen
   を非表示化。

2. 日本語の大きな
   「＋ 写真を選ぶ」
   ボタンへ変更。

3. 保存前に選択した写真をサムネイル表示。
   ファイル名・容量も確認できる。

4. 間違えた写真は
   「この写真を外す」
   で保存前に解除可能。

5. 旧固定画像しかない商品は
   「現在公開中の画像」
   を写真タブ内にも表示。

6. 新しい写真を1枚保存すると
   旧固定画像から新しいメイン写真へ切替わることを明記。

7. PCではドラッグ&ドロップにも対応。

既存API / DB / Worker変更なし。
