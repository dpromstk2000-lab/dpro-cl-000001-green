DPRO GREEN CONTACT R3.11 / FINAL HARDENING
2026-09-27

目的:
R3.10.4 ZERO-JUMPで実機PASSした動作を守ったまま、
CONTACT内部に残っていた旧処理を整理する。

主な変更:
1. contact-green.js をR4へ更新
   - renderMessages()の無条件 scrollTop=scrollHeight を廃止
   - 新しい会話を開く時だけ最新位置へ
   - 再読み込み時はmessage ID基準で閲覧位置を復元
   - タブ復帰時の自動再読込は autoRefresh=true の時だけ
   - 非同期中に別会話へ移動した場合の古いレスポンス描画を防止
   - message DOMへ data-message-id を付与

2. 添付履歴をbase rendererへ統合
   - array indexで添付を後付けする方式を廃止
   - Workerが返す message.id と同じメッセージDOMで直接描画
   - 追加API fetch / MutationObserver依存を削除
   - 画像の表示枠を200pxで先に確保しレイアウトずれ防止

3. green-contact-standard-r3.js をR3.4へ
   - deprecated DOMNodeRemovedを廃止
   - object URLを明示的にrevoke
   - 添付送信後は正式にbottom refresh

4. contact-green.html
   - 古いquery stringを更新
   - standard / ZERO-JUMP CSS・JSをHTMLから明示ロード
   - config.jsの動的loader依存を解除

5. contact-green-config.js
   - 設定専用へ整理
   - R3.10.4で必要だったvisibility抑止overlayを撤去
   - BUILD QAの古い通常セッション除去だけ維持

維持:
- LINE text双方向
- LINE画像/PDF/Office/TXT/CSV添付
- private Storage
- 送信確認
- R3.10.4 ZERO-JUMP
- BUILDアクセス遷移
- Security文言

変更なし:
Worker / SQL / Supabase / Secret / LINE公式設定
