DPRO GREEN SHOP V3-C OWNER UI
2026-09-27

目的
====
オーナーが商品管理を「簡単に・見やすく・間違いにくく」行える管理画面。

変更ファイル
============
green-shop-owner.js
config.js

主な改善
========
- 商品一覧を写真付きカード化
- 登録商品 / 公開中 / 写真登録済 / 在庫注意 を上部に表示
- 検索 / 商品種別 / 公開状態フィルタ
- 商品編集を5ステップ:
  ①基本
  ②写真
  ③販売方法
  ④受取方法
  ⑤公開
- 写真は最大6枚
- PC / スマホから選択
- メイン写真指定
- 写真並べ替え
- 写真削除
- 写真説明
- 商品種別:
  観葉植物 / 鉢・鉢カバー / 小物・用品 / ギフト / その他
- 販売方法:
  通常販売 / 取り置き / レンタル / 問い合わせ
- 受取方法:
  配送 / 店頭受取 / 自店配達 / レンタル配達
- 在庫方式:
  数量管理 / 在庫数を表示しない / 問い合わせ
- レンタル月額
- おすすめ指定
- 下書き / 公開 / アーカイブ
- 商品複製
- 完全削除は商品コード再入力で誤操作防止
- 旧固定画像商品は警告表示するが既存公開を壊さない

重要
====
このPHASEでは公開SHOPの詳細ギャラリー・おすすめ・セットの完全動的化はまだ行わない。
次のV3-Dで公開SHOP側をV3 APIへ最適化する。

Square実決済はOFFのまま。
BUILD ACCESSは引渡し前まで維持。
